blocky — Dark Style Guide

Dark is the low-light variant of blocky, the browser brick-building sandbox. Auto mode resolves OS dark to this theme. Chrome and stud-grid lines shift to the cyan/teal HUD palette, while the brick material colors stay identical to Light so a build reads the same in either theme — only the surrounding HUD re-themes.

Ghost Placement States

A translucent cursor brick follows the pointer and snaps to the stud grid. Green = the brick connects and will place; red = it would float or collide and is rejected. These map to --color-ok and --color-danger.

Placeable — grounded / connects to a stud
Invalid — would float or collide

Stud-Grid Build Surface

The baseplate the structure rests on. Grid lines use --color-grid at low alpha to suggest the stud pitch without competing with the bricks.

Toolbar & Buttons

The toolbar holds the edit controls: rotate, undo/redo, new, save/share, and reset view. Buttons share one base; --danger marks destructive actions (clear / delete), and the --focus ring keeps every action keyboard-reachable.

States, left to right: default, hover, keyboard-focus ring, disabled.

Dialogs

Modal sheets for confirmations (new / clear) and the keyboard-shortcut reference. Panels use --color-panel-strong; <kbd> keys are tinted with the grid accent.

Clear the build?

This removes every brick from the baseplate. You can undo it with Ctrl+Z.
